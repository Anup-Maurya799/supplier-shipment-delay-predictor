# 🚚 Supplier Shipment Delay Predictor

AI-powered logistics dashboard that analyzes shipment data,
traffic conditions, weather, supplier performance and predicts
shipment delay risk.

## 🚀 Live Demo

https://supplier-shipment-ai.streamlit.app

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Plotly
- TomTom Traffic API
- Open-Meteo API

## 🤖 Features

- Executive logistics dashboard
- AI-powered delay prediction
- Shipment analytics
- Live traffic monitoring
- Weather analysis
- Supplier performance analytics
- AI-generated logistics insights
